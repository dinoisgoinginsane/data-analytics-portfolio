# data-analytics-portfolio
Portfolio projects in data analytics

### 1. Real Estate Agency Analysis
- Tools: SQL, Yandex DataLens
- Description: Analysis of real estate data to identify pricing factors and market trends.
- Files: SQL queries, analytical report, interactive dashboard

### 2. HH.ru Job Market Analysis
- Tools: SQL, Python, Pandas, Yandex DataLens
- Description: Analysis of HH.ru job postings to explore the Data Analyst job market, including salaries, experience, work formats, locations, and required skills.
- Files: SQL queries, analytical report, interactive dashboard

### 3. Dark Forest Game Analysis
- Tools: SQL, Python, Pandas, Yandex DataLens
- Description: Analysis of game data to explore player performance, win rates, game outcomes, and factors affecting results.
- Files: SQL queries, analytical report, interactive dashboard
